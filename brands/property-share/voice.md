# Voice — PropertyShare

- Plain, precise, a little understated. Explain like a good teacher; no hype.
- Short sentences. Concrete examples ("250,000 shares = 25% of each rent deposit while you hold them").
- Honest about limits. Saying what the software does *not* do builds credibility.
- Technical words are fine for developers; define them for everyone else.

Use: build, open source, test network, rent split, allowlist, audit (as a future step), feedback.
Avoid: revolutionary, game-changer, unlock wealth, democratize (overused), to the moon, emojis beyond one per post, hashtags beyond two.

## Calls to action allowed
- Read the code / star the repo.
- Try it on a test network.
- Give feedback / open an issue.
- Read the explainer.
